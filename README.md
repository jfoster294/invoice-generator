# Invoice Generator

A front-end invoice generator where users can add clients, create invoice items, calculate totals, save invoices, and print a clean invoice layout.

## Live Demo

https://jfoster294.github.io/invoice-generator/

## Features

- Add business information
- Add client information
- Add invoice number
- Add invoice date
- Add due date
- Add invoice line items
- Calculate quantity and price totals
- Calculate subtotal
- Calculate tax
- Apply discount
- Calculate final invoice total
- Remove line items
- Save invoice locally
- Clear invoice
- Print invoice
- Responsive design for mobile and desktop

## Built With

- HTML
- CSS
- JavaScript
- Local Storage
- Print CSS

## Project Goal

This project was built as part of my front-end developer portfolio to practice dynamic forms, calculations, rendering line items, local storage, print layouts, and responsive design.
